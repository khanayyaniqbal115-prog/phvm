Control VMs and users right from Discord using phvm! commands. Create an application at discord.com/developers/applications, add a Bot, enable the Message Content Intent, copy its token below, then invite it to your server with the bot scope. Anyone can run phvm!register to auto-create an account — username, email and password are generated automatically and DMed to them — then phvm!create for a free VM; admin-only commands require Administrator permission on the server. Run phvm!help in Discord to see all commands once it's connected.
