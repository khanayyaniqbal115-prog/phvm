Go live on your own domain

  1. Open the Domains tab and add your domain (for example example.com).
  2. Choose how visitors reach it: a public IPv4 (A record) or a Cloudflare Tunnel (works without any public IP).
  3. Follow the two short steps shown for that choice. HTTPS is turned on automatically either way.

DNS records to create

At your domain provider (Cloudflare, Namecheap, GoDaddy…), add:
Type  A   Name  @ (or www)   Value  {{ server_ip or 'server IP' }}
If you use Cloudflare, set the record to DNS only (grey cloud) until the certificate is issued. DNS changes can take a few minutes to spread.
{% if cf_auto %}
Nothing to do by hand. When you connect the domain, the panel adds it to your Cloudflare Tunnel and creates the DNS record for you.
The domain must already be in the Cloudflare account that owns the tunnel (change its nameservers to Cloudflare first).
{% else %}
In Cloudflare Zero Trust → Networks → Tunnels → your tunnel, add a Public hostname:
Hostname  your domain (e.g. example.com)
Service    HTTP  localhost:80
Cloudflare creates the DNS record for you. Repeat for each name you connect (for example also www.example.com).
