Deploy from Git

Downloads the code into /root/bot, installs dependencies and restarts the bot if it's running. Your .env and Python venv are kept. Progress shows in the Console tab.

Environment variables

One KEY=value per line (quote values that contain spaces). Loaded before your startup command. Stored only on your machine.
{% if docker %}

Crash alerts

Get a Discord message with the last log lines when your bot crashes or runs out of memory. Create a webhook in Discord: channel settings → Integrations → Webhooks. Leave empty and Save to turn alerts off.
{% endif %}

Dependencies

Runs npm install if there's a package.json and pip install -r requirements.txt if there's a requirements.txt.
