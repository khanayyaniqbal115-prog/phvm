Cloud-init behaviour

Every new VM receives a cloud-init seed that:

  • Enables root with an auto-generated password
  • Keeps the OS default sudo user (ubuntu / debian) with the same password
  • Enables SSH password authentication and PermitRootLogin
  • Resizes the root filesystem to the full disk
  • Installs common tools (curl, vim, htop, openssh-server, qemu-guest-agent…)
