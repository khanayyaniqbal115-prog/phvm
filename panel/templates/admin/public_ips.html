Public IPv4 Pool

Store and assign dedicated IP addresses when deploying VMs — each one gets bound fully to a VM (every port), not just SSH.

How this works: adding an IP here does two things automatically — (1) adds it to this host's network interface via netplan, so the host can actually receive traffic for it, and (2) when you assign it to a VM, sets up a private bridge + NAT rules so that IP's traffic goes straight to that VM. Make sure the IP is already routed to this server by your provider (or your IP-leasing service's tunnel) before adding it here — this only handles the "last mile" from the host to the VM, not getting the IP to the host in the first place.
