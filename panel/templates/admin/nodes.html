Add a Remote Node

Remote nodes actually run VMs — when you create a VM on a remote node, the panel downloads the image, builds cloud-init and starts QEMU on that machine, not on this panel host. The other server needs qemu-system-x86, qemu-utils, cloud-image-utils and wget installed.

{% if node_register_token %} 
export PHvm_PANEL_URL={{ panel_url }}
export PHvm_NODE_TOKEN={{ node_register_token }}
export PHvm_NODE_NAME=node-2
export PHvm_AGENT_PORT=5050
python3 node.py

Once it prints [OK] Registered as node_id=... and Agent API on 0.0.0.0:5050, the node appears below within ~30s. Make sure port 5050 (or whatever PHvm_AGENT_PORT you chose) is reachable from this panel — open it in your firewall/security group.

No registration token set yet — generate one first, then run node.py on the other server with it.

About acceleration

KVM — hardware virtualization via /dev/kvm (fast).

TCG — QEMU software emulation fallback when KVM is missing (slower, works everywhere).

When creating a VM, pick the node from the Node dropdown — VMs on a remote node run entirely on that machine, including their SSH access.
